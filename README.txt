BIZFINDER — серверный поиск организаций без платной подписки на карту

ТРЕБОВАНИЯ
- Node.js 18 или новее.
- Интернет-соединение на компьютере/сервере, где запущен BIZFINDER.
- Для обычного локального теста не нужны API-ключи и платная подписка.

ЗАПУСК НА WINDOWS
1. Распакуйте архив в отдельную папку.
2. Установите Node.js 18+ с https://nodejs.org/ (если ещё не установлен).
3. Откройте папку проекта.
4. В адресной строке Проводника введите cmd и нажмите Enter.
5. Выполните: npm start
6. Откройте: http://localhost:8787
Не открывайте index.html двойным щелчком: API-поиск работает через server.js.

ЗАПУСК НА macOS / Linux
1. Откройте терминал в папке проекта.
2. Выполните: npm start
3. Откройте: http://localhost:8787

ЧТО ДЕЛАЕТ СЕРВЕР
- /api/health — проверка состояния локального backend.
- /api/geocode — серверный геопоиск Photon с резервным Nominatim.
- /api/search — поиск организаций в OpenStreetMap Overpass.
- Сервер отправляет Overpass POST-запросом с User-Agent; если зеркало отвергает метод, пробует GET.
- Два публичных зеркала вызываются последовательно с ограниченным общим временем ожидания. GET используется первым; для ответов 400/405/406/413/414/415/429 выполняется ограниченная попытка POST.
- Результаты кэшируются в памяти на 10 минут, одинаковые параллельные запросы объединяются.
- Есть базовое ограничение частоты запросов и ограничение радиуса 1–50 км.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Карта: OpenFreeMap / MapLibre, отдельная от поиска организаций.
- Бизнесы: OpenStreetMap, НЕ Яндекс Карты.
- Публичные Overpass-зеркала бесплатны, но не дают SLA и могут ограничивать нагрузку. Серверный proxy решает браузерные CORS/preflight-проблемы и позволяет задать User-Agent, но не может гарантировать, что публичное зеркало примет запрос с любого хостинга.
- Для стабильной коммерческой эксплуатации следует развернуть собственный экземпляр Overpass или использовать лицензированный источник данных.
- OSM не гарантирует наличие телефонов, email, сайтов, рейтингов и отзывов. Отсутствующие сведения не выдумываются.
- CRM пока хранится в localStorage конкретного браузера. Для совместной работы сотрудников нужен отдельный backend БД и авторизация.

ПРОВЕРКА BACKEND
Откройте http://localhost:8787/api/health. Должен появиться JSON с ok:true и version:1.1.1. После замены server.js обязательно остановите старый сервер сочетанием Ctrl+C и запустите npm.cmd start заново.
